## About the vectors
The ministry supplied a JPG only, so `scripts/vectorize_mhup.py` traces it with potrace: the two inks are separated by region, upscaled 4× and traced into smooth Bézier curves. 635 sub-paths. Rendered back at the original size, the trace differs from the JPG on about 0.06% of pixels (edges only). This is good for large-format print, but it is a reconstruction, not the ministry's master artwork. Replace these files with the official vector as soon as the ministry provides one.

Rules: use as supplied, with no recolouring, cropping into the artwork or redrawing. The navy and grey only read on white or light backgrounds.
For the joint lockup see `brand/logo/cobrand/` (generated by `scripts/build_cobrand.py`).
